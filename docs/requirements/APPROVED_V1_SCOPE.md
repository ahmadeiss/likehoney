# Approved V1 Scope — Like Honey

> **Immutable guardrail.** This document defines what Like Honey V1 may contain.
> AI agents must **never silently expand scope**. Any feature outside this list
> must be **explicitly approved** before implementation. When in doubt, ask first.

## In V1

- Professional bilingual website (Arabic + English, RTL/LTR)
- Customer storefront
- Guest checkout (no customer accounts)
- Product browsing, search, and filtering
- Product variants
- Cart tied to a visitor session
- Checkout customer information collection
- **Cash on Delivery**
- Product / social-post external links
- Dynamic content pages
- Employee dashboard (POS / store sales recording)
- Admin dashboard
- Products
- Supplier companies
- Categories
- Inventory
- Order management
- Store sale inventory recording
- Permissions (roles)
- Basic monthly operational / sales reports
- Web application only

## Not currently included in V1

- Customer user accounts
- Full loyalty program
- Complete accounting system
- Payroll
- Tax / accounting ledger
- Mobile native application
- SMS notifications
- WhatsApp notifications
- Email order-status notification system
- Delivery company integration
- GPS tracking
- Automatic social media synchronization
- External integrations unless separately approved
- Finalized online Visa payment integration unless separately approved

## Rules of engagement

1. Scope is a guardrail, not a suggestion.
2. Unlisted functionality is explicitly **out of scope**.
3. Request separate approval before building anything unlisted.
4. These boundaries may only change through an explicit scope amendment.
